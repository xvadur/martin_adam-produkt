# Martin Barczi — interactive homepage study

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Static HTML, CSS and JavaScript, as delegated in the implementation brief. No build dependency.

## Users and purpose

Potential customers considering Martin's online-assistant services. Their task is to understand his work and experience, read actual client references and prepare a contact email. Adam is comparing three progressively bolder homepage studies with the same underlying content.

## Confirmed constraints

The existing home page's exact main paragraphs and section order are preserved. Six services, five cooperation steps, four benefits, full original about text and three complete actual references. Real existing media only. No invented KPI, clients, stars, avatars or AI-agency positioning. Detail pages, blog and certifications link to onlineasistent.sk. The form prepares a mailto draft; it does not transmit a form submission. This comparison route is noindex.

## Visual reference selected by the user

AI Automation Agency / Orrin — Long Exposure Agency Template, by Kedhareswer Naidu. The user selected this as the middle, interactive direction. Its pale surface, Newsreader heading character, centered heading above a wide dark visual, soft accordion layout and dark closing contact provide the compositional reference. All animation and diagrams in this adaptation are original code describing Martin's actual service categories.

## Evidence

`../../design/beautifier/source/home-content.json`, shared real imagery in `../shared/assets/real/`. No verified client portraits or new service metrics are available.

## Accessibility

Content remains readable without JavaScript. Native disclosure headings with keyboard controls; manual quote navigation; visible motion pause; reduced-motion support; labeled fields and native form validation. Motion stops offscreen and in background tabs.
