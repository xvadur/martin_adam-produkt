# Martinov základ značky

**Pracovný podklad pre brand book a budúci web, verzia 0.1, 22. 10. 2026.**

Základ tvorí [profil, publikum, ponuka, hlas a dôkazy](ZAKLAD-ZNACKY.md) a [vizuálny brief odvodený z pôvodného webu](VIZUALNY-BRIEF.md). Nadväzuje na [kontext rozhodnutí](../docs/KONTEXT-A-ROZHODNUTIA.md), [zdrojový audit](../research/web/2026-10-22/README.md) a [kurátorský výber realitného výskumu](../research/reality/INDEX.md).

Toto je stabilný zdrojový základ na rozhodovanie. **Finálny brand book ešte nevznikol:** nemáme prijatý nový vizuál, potvrdenú hierarchiu ponuky ani odovzdané všetky materiály. Nevznikli nové logo, tokeny, frontend ani nasadenie.

| Vrstva budúceho brand booku | Dnešný stav |
| --- | --- |
| Pôvod a pracovné zadanie | Zachytené z konkrétnej konverzácie a aktuálneho pokynu. |
| Profil, publikum a prínos | Doložené verejné východiská + označené pracovné interpretácie. |
| Ponuka a dôkazy | Inventár dnešného webu; chýbajú potvrdenia budúcej ponuky a pôvodné case podklady. |
| Hlas a spôsob vysvetľovania | Odvodené princípy s vlastnými skúšobnými formuláciami. |
| Fotografia a materiály | Existujúce verejné použitia zmapované; originály a rozsah práv treba doplniť. |
| Farby, typografia, materiál a kompozícia | Pôvodné hodnoty sú merané referencie. Nové hodnoty zostávajú otvorené. |
| Ukážka jednej obrazovky | Neskorší dizajnový krok; teraz sa nestavia. |
| Prijaté pravidlá a živá referencia | Odvodia sa až z konkrétne prijatej vizuálnej ukážky. |

Používame rovnakú disciplínu ako pri XVADUR Stacku: zdroje → konkrétne rozhodnutia → skutočný obsah → neskoršia vizuálna skúška → prijaté pravidlá. Martin dostáva vlastný charakter, nie automaticky oranžovú či neumorfickú tému XVADURu.
